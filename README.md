# MEMRISYS 2026 Conference Calendar

## Gallery update v2

- Photos whose timestamp does not match a conference session are now imported automatically into an **Unclassified** Gallery group instead of being skipped.
- The import review still lets you manually assign those photos to any programme item or choose **Do not import this photo**.
- Dark mode now uses white primary text throughout dialogs, Gallery cards, form controls and other surfaces. Native select menus are also told to use dark color controls on supported Android Chrome versions.
- Existing timestamp matching, starred-session prioritization, thumbnails and manual presentation photo attachment remain unchanged.

## Deployment
Replace `app.js`, `styles.css`, and `service-worker.js` in the repository root and commit to `main`. `README.md` is optional.
